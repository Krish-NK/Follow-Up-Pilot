QUICK SUPPORT

Having trouble opening FollowUpPilot?

These steps solve the most common local setup and browser problems.

?

1. Recommended browsers

Use an up-to-date version of Google Chrome, Microsoft Edge, Firefox or Safari. Safari is a good choice on Mac. Chrome and Edge are good cross-platform choices.

2. Opera shows 403 / Access Denied

Try a Private window first. If it still happens, temporarily turn off Opera VPN and proxy, then allow or disable ad-blocking and privacy extensions for this local address. Re-enable protections after testing. You can also try http://localhost:5000/.

3. Page cannot be reached

Keep the Terminal or PowerShell window open while using the app. If the server stopped, return to the project folder, activate .venv, and run python app.py again.

4. Check the app connection

Open the health check. A working app returns status: ok. If it fails, check the server output in Terminal for the error.

5. Port 5000 is busy

Start on another port: macOS/Linux PORT=5001 python app.py. Windows PowerShell $env:PORT=5001; python app.py. Then open http://127.0.0.1:5001/.

6. Still stuck?

Try another supported browser and check whether the same address works there. If only one browser fails, its VPN, proxy, extension or privacy settings are likely involved. If every browser fails, inspect the server log first.

Privacy note: FollowUpPilot currently runs on your own computer. Do not share your local address as a public website. Browser-generated 403 pages are different from errors returned by the app.
